η Эта — лаунчер Minecraft (macOS 11+, Intel) · версия интерфейса

УСТАНОВКА
1. Перетащите «Eta» (Эта) в «Программы».
2. Первый запуск: правый клик → «Открыть» → «Открыть» (приложение не подписано сертификатом Apple).
   Если не открывается: Терминал → xattr -cr "/Applications/Eta.app"

ЧТО УЖЕ ЕСТЬ
- Страница загрузки при старте.
- Главная: выбранная сборка, кнопка «Играть», быстрый выбор сборки, недавние сборки, новости.
- Сборки: каталог как на Modrinth (поиск, источник Modrinth / CurseForge, загрузчик, версия игры,
  категории, сортировка, страница проекта с версиями, установка) и «Мои сборки» (создать, выбрать,
  переименовать, копировать, удалить).
- Аккаунты: оффлайн-аккаунты по нику (UUID как у серверов в оффлайн-режиме), выбор и удаление.
- Настройки: папка игры, память, Java, аргументы JVM, размер окна, тема, загрузки.

ЧТО БУДЕТ ДАЛЬШЕ
Каталог сейчас показывает примеры. Следующий шаг — загрузка сборок и модов с Modrinth и CurseForge,
скачивание Minecraft и Java и запуск игры, вход через Microsoft.

macOS 11 Big Sur или новее · Intel x64 (Apple Silicon — через Rosetta 2) · 4 ГБ ОЗУ (8 ГБ для больших сборок)
