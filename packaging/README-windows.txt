Эта — лаунчер Minecraft (Windows x64)

Запуск: двойной клик по Eta.exe. Установка не нужна; файл можно положить куда угодно.

Windows SmartScreen при первом запуске может показать «Система Windows защитила ваш компьютер» —
сборка не подписана сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

Данные лаунчера (настройки, аккаунты, сборки, Java и файлы игры): %APPDATA%\Eta
Папку игры можно поменять в «Настройки».
